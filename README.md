# bobo198504

Windows utilities, written to stay small and portable — no installers, no registry.

## [Apex](https://github.com/bobo198504/Apex) — 端, a tool set for Windows

| Feature | What it does |
|---|---|
| **Silky Scroll** (丝滑滚动) | Smooth mouse-wheel scrolling everywhere. Touchpads and free-spinning wheels are told apart and handled separately |
| **Auto IME** (自动输入法) | Automatic input method (IME) switching, by the program or control that has focus |
| **Keep Awake** (保持唤醒) | Keep the machine awake / prevent sleep and keep the screen on, per program |
| **Media Control** (媒体控制) | Monitor brightness and screen-off per display; volume and mute per application |

Portable, bilingual (Chinese / English), and each feature owns its own switch and exclude list.

## [SmoothWheelScroll](https://github.com/bobo198504/SmoothWheelScroll) — smooth scrolling for REAPER

A REAPER extension, and the source of the smoothing model that Apex's scrolling is built on.

## [Lertaro](https://github.com/bobo198504/Lertaro) — a Windows launcher (my fork)

My fork, which keeps the smooth-scrolling engine that upstream has since removed.
